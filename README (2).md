# 🤟 Hand Gesture Detector

A real-time hand gesture detection web app powered by **YOLOv8**.

## Detects 5 Gestures:
| Gesture | Fingers |
|---|---|
| ☝️ one | 1 finger |
| ✌️ two | 2 fingers |
| 🤟 three | 3 fingers |
| 🖖 four | 4 fingers |
| 🖐️ five | 5 fingers |

## Features:
- 📸 **Image Detection** — Upload a photo and detect hand gestures
- 🎥 **Video Detection** — Upload a video for frame-by-frame detection

## Dataset:
Hand Gesture Recognition by Lebanese University  
https://universe.roboflow.com/lebanese-university-grkoz/hand-gesture-recognition-y5827

## Model:
YOLOv8n fine-tuned via transfer learning · 100 epochs · 416×416
